# PromisePatch identity

The mark is a near-closed promise loop that also resolves into a `P`. Its deliberate break is
bridged by a compact structural insert: a selective repair that restores continuity without
pretending the break never happened. The small extension into the counter makes the patch legible
in colour while preserving a strong single-colour silhouette.

## Files

- `promisepatch-logo-on-light.svg` — primary horizontal lockup on light surfaces
- `promisepatch-logo-on-dark.svg` — reversed horizontal lockup on dark surfaces
- `promisepatch-icon-on-light.svg` — standalone icon on light surfaces
- `promisepatch-icon-on-dark.svg` — standalone icon on dark surfaces
- `promisepatch-logo-monochrome.svg` — single-colour horizontal lockup using `currentColor`
- `promisepatch-icon-monochrome.svg` — single-colour icon using `currentColor`
- `promisepatch-brand-sheet.svg` — presentation and small-size comparison sheet

## Usage

Keep clear space around the lockup equal to the icon stem width (one quarter of the icon's
height). Use the standalone icon below 140 px of available horizontal space. The full icon is
designed to remain legible at 16 px; at that size, do not add a container stroke or shadow.

The wordmark uses a modern system-sans stack headed by Inter and Geist so the source remains
editable. For fixed-production artwork, convert the wordmark to outlines using the final product
font before sending it to a vendor. The symbol itself is already fully outlined vector geometry.
